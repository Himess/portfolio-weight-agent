While you are not looking

It does not roam.
It taps you on the shoulder.

The agent has no background life, and that is Binance's rule rather than ours: the MCP session is bound to your own client, with no machine-to-machine grant. Nothing runs unattended.

So the server watches the band instead. When a position crosses it you get a message carrying the agent's verdict — including the verdict to wait, which is the one a threshold bot can never send.
